# cpu-simulator

一个用 C++17 从零实现的 RISC-V（RV32I）**指令级**模拟器。它读取十六进制机器码，按取指 / 译码 / 执行 / 写回四步逐条模拟，能执行 7 条指令子集，并把每一条的执行轨迹打印出来。

## 支持的指令

| 指令 | 格式 | 做什么 |
|------|------|--------|
| addi | I | 把寄存器 rs1 的值加上立即数 imm，写入 rd |
| add  | R | 寄存器 rs1 与 rs2 相加，写入 rd |
| sub  | R | 寄存器 rs1 减去 rs2，写入 rd |
| and  | R | 寄存器 rs1 与 rs2 按位与，写入 rd |
| or   | R | 寄存器 rs1 与 rs2 按位或，写入 rd |
| lw   | I | 从地址 rs1 + imm 读出 4 字节，写入 rd |
| sw   | S | 把 rs2 的 4 字节写入地址 rs1 + imm |

## 编码速查

| 指令 | opcode | funct3 | funct7 |
|------|--------|--------|--------|
| addi | 0x13 | 000 | — |
| add  | 0x33 | 000 | 0000000 |
| sub  | 0x33 | 000 | 0100000 |
| and  | 0x33 | 111 | 0000000 |
| or   | 0x33 | 110 | 0000000 |
| lw   | 0x03 | 010 | — |
| sw   | 0x23 | 010 | — |

`add` 与 `sub` 的 opcode 和 funct3 完全相同，只能靠 funct7 区分。

## 第一版验收

**输入**：9 个手工编码的十六进制机器码字，硬编码在源码里，对应下面这段程序

```
addi x1, x0, 100      # x1 = 100
addi x2, x0, 8        # x2 = 8
sw   x1, 0(x2)        # mem[8] = 100
lw   x3, 0(x2)        # x3 = 100
addi x4, x0, 22       # x4 = 22
add  x5, x3, x4       # x5 = 122
and  x6, x5, x4       # x6 = 18
or   x7, x5, x4       # x7 = 126
sub  x8, x5, x4       # x8 = 100
```

**执行后**：`reg[5] == 122`、`reg[6] == 18`、`reg[7] == 126`、`reg[8] == 100`，且 `mem[8]` 处 4 字节等于 100。

**另外要打印**：每执行一条指令输出一行轨迹，格式为 `pc：指令名 → 写回目标寄存器 新值`，9 行不多不少。

判定标准：任何人拿到这段输出，能靠自己核对出上面四个寄存器值是否正确。

## 第一版明确不做

- 不含跳转与分支（beq / bne / jal），因此跑不了循环，程序只能是直线展开的
- 不含异常与中断，非法指令直接报错退出
- 只有 32 位对齐的整字访存，不处理半字、字节和未对齐地址
- `x0` 恒为 0，任何写入都丢弃

## 构建

```
g++ -std=c++17 -O0 -g -o sim main.cpp
./sim
```

要求 gcc 12 及以上。Linux 与 Windows(MSVC) 均可。
